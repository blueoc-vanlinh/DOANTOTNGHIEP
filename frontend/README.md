# Inventory Intelligence Platform

Frontend React cho hệ thống quản lý kho tích hợp AI Forecast.

## Chức năng chính

- Trang giới thiệu public, đăng nhập và dashboard nội bộ.
- Quản lý sản phẩm, danh mục, nhà cung cấp, kho, tồn kho.
- Lập phiếu nhập, phiếu xuất, hóa đơn và giao dịch kho.
- AI Forecast, AI Data, benchmark model và khuyến nghị nhập hàng.
- Quản trị người dùng, vai trò, audit log và thông báo.

## Cấu hình

Tạo file `.env` từ `.env.example`:

```bash
VITE_API_URL=http://127.0.0.1:8000/api/v1
```

## Lệnh chạy

```bash
npm run dev
npm run type-check
npm run build
```
